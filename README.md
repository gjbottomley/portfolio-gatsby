## 🚀 Quick start

**Dependancies**

    ```
    nvm install 20.8.0
    npm install -g gatsby-cli
    ```

**Start developing.**

    Navigate directory and start it up.

    ```
    cd portfolio-gatsby/
    gatsby develop
    ```

**Open the code and start customizing!**

    Your site is now running at http://localhost:8000!

    Edit `src/pages/index.js` to see your site update in real-time!

**Build.**

    Lets build.

    ```
    cd portfolio-gatsby/
    gatsby build
    ```
